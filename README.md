# Functional DDD em Kotlin

Código da série **Functional DDD** do canal [@pasquadev](https://youtube.com/@pasquadev) — membros exclusivo.

Baseado no livro [Domain Modeling Made Functional](https://pragprog.com/titles/swdddf/domain-modeling-made-functional/) de Scott Wlaschin (F#), traduzido para **Kotlin + Arrow-kt**.

| 04 | Domain Modeling com Tipos: Value Objects, Entities, Aggregates | `Domain.kt` |
